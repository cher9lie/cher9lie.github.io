DBCloud 并不是直接处理影像的主程序。它更像一个软件入口，负责账号登录、许可验证和下载教学版应用；真正完成航片建库、空中三角测量、DEM/DOM 生产和 DLG 测图的是 DBCloud 中的 **DoubleGrid（网络版）/ DPGrid**。

这篇教程用一组带 POS 信息的无人机航片和地面控制点，走完一条较完整的内业流程。最终应得到：

- 空中三角测量和平差精度报告；
- DEM 数字高程模型；
- DOM 正射影像及拼接线；
- DLG 矢量数据与整饰后的成果图。

> 本文截图来自教学版软件。不同版本的菜单名称可能略有差别，但处理顺序和判断标准基本一致。

## 1. 开始之前

### 1.1 软件和许可

教师或管理员需要先在达北云平台建立用户组并取得许可。学生通过教师提供的授权链接注册，安装 DBCloud 后登录，在“软件宝库”中下载或打开 **DoubleGrid（网络版）**。

如果 DPGrid 能打开，但“匹配连接点”等计算任务没有反应，先回到 DBCloud 检查是否仍处于登录状态，以及当前账号是否具有可用许可。

### 1.2 准备数据

至少需要以下内容：

1. 原始航片。照片应保留相机参数和 POS 信息，不能只留下经过社交软件压缩的副本。
2. 控制点坐标文件。本文示例为 TXT 文本。
3. 控制点点位照片或点位分布图，用于人工刺点。
4. 足够的磁盘空间。连接点、DEM、单片正射和拼接成果会显著增加工程体积。

示例控制点文件第一行是点数，后续每行依次为点号、X、Y、Z：

```text
20
1001 246010.155792352 3381062.768458493 13.246000
1006 246464.950255404 3380691.569715153 21.771000
...
```

坐标字段的顺序、单位和坐标系必须与软件设置一致。不要只确认“能导入”，还要检查点位是否落在测区的合理位置。

### 1.3 工程目录

DPGrid 对路径比较敏感。工程路径不要包含中文、空格和特殊符号，也不要把工程建在层级很深的目录中。可以采用下面的结构：

```text
D:\photogrammetry\
├─ raw_images\
├─ gcps\
└─ project01\
```

`project01` 应当是一个空文件夹。处理过程中不要随意移动或重命名其中的文件。

## 2. 新建工程并导入航片

打开 DPGrid，选择“文件 → 新建工程”，指定刚才准备的空文件夹。进入影像与 POS 设置窗口后，单击“添加影像”，导入全部原始照片。

![导入航片并设置 POS 参数](./01-project-import.png)

重点检查以下参数：

- **航高**：填写本次飞行的实际相对航高。示例数据使用 150 m；老师的另一组资料中使用 180 m，因此不能把某个数值当作固定参数。
- **去除转弯片 / Remove Turn**：建议勾选，用于排除航线转弯时姿态变化较大的照片。
- **自动选点 / Auto Tie Points**：此处先取消，后面再统一执行连接点匹配。
- **影像和 POS 对应关系**：影像名、POS ID 和记录数量应当一致。

导入后，主窗口会以点列或航带形式显示曝光位置。滚轮缩放，检查航带是否连续、方向是否合理，并删除边缘、转弯或明显离群的多余影像。

![检查航带排列并删除异常影像](./02-flight-layout.png)

修改完成后依次执行“文件 → 保存”和“文件 → 同步”。只保存而不进行同步，主界面可能仍显示旧的航带状态。

## 3. 导入地面控制点

选择“文件 → 地面控制点”，单击“引入 / Import”，选择控制点 TXT 文件。

![导入地面控制点坐标](./03-gcp-import.png)

保存后，控制点编号应当出现在测区中，并与控制点分布图大致对应。

![控制点与航带的整体分布](./04-gcp-layout.png)

如果所有控制点聚在角落或远离航片范围，通常不是“显示比例不对”，而是坐标顺序、投影、单位或带号不一致。应先修正坐标问题，再继续后面的计算。

## 4. 匹配连接点

选择“定向生产 → 空中三角测量 → 匹配连接点”。在本次教学数据中：

- 使用 iBundle 平差链路；
- 取消“精细匹配”；
- 其余参数保持教学数据的默认值。

![连接点匹配参数](./05-tie-point-parameters.png)

连接点是不同影像中同一地物的同名像点。它们把多张航片连接成统一的摄影测量网，是后续空三平差的基础。运行完成后，进入结果概览，检查影像是否已连成连续测区，不能只看任务窗口是否消失。

![连接点匹配后的测区概览](./06-tie-point-overview.png)

若匹配任务完全没有启动，优先检查：

1. DBCloud 是否仍登录、许可是否有效；
2. 工程路径是否含中文或特殊字符；
3. 原始影像是否丢失、被移动或无法读取；
4. 运行库和 DirectX 组件是否完整。

## 5. 人工刺点与空三平差

### 5.1 打开平差编辑

选择“定向生产 → 空中三角测量 → 平差与编辑”。软件会显示叠拼底图、航片网和预测控制点。

![平差编辑界面中的影像与控制点](./07-adjustment-overview.png)

此时的圆形点位只是预测位置，不代表已经完成实测刺点。选择“处理 → 匹配加连接点”，按控制点分布图依次处理。

### 5.2 选择控制点

控制点不应集中在测区一侧。教学数据可以先选择：

- 左上、右上、左下、右下四个角部点；
- 测区中心附近一个点；
- 再补充 2～3 个分布均匀的点。

这比单纯增加同一区域的点数更重要。本文示例最终使用了 7 个控制点。

### 5.3 精确刺点

打开对应点号的现场照片，在参考影像和其他覆盖该点的影像中寻找同一位置：

1. 鼠标右键选择当前影像；
2. 鼠标左键移动像点；
3. 使用 `Ctrl + 鼠标滚轮` 调整显示尺度；
4. 让各影像中的标记落在同一清晰、稳定的地物位置；
5. 被树木、车辆或建筑阴影遮挡的影像可按空格键剔除，不参与该点计算。

![结合点位照片进行精确刺点](./08-gcp-marking.png)

自动匹配只能作为初始定位，不能替代人工复核。点位应优先落在清晰角点、道路标志交点等稳定目标上，避免模糊边缘、树冠和阴影边界。

确认点号 ID 后单击“保存”，关闭当前点的小窗口。成功完成的控制点会由圆形预测符号变为三角形加十字符号。

![完成刺点后的控制点分布](./09-marked-gcp-result.png)

### 5.4 选择 iBundle 并设置精度

运行平差前，在“处理 → 平差方式”中明确选择 **平差软件 iBundle**。

![选择 iBundle 平差软件](./10-select-ibundle.png)

如果跳过这一步，“运行平差”可能只弹出黑色命令行窗口，而没有生成可用报告。

选择“处理 → 运行平差”，进入 Adjust Frame Camera。

![进入框幅式影像区域网平差程序](./11-adjust-frame-camera.png)

单击“设置”，按照数据质量填写精度。教学示例中：

- 控制点平面精度：0.05 m；
- 控制点高程精度：0.05 m；
- 像点精度 x、y：0.00231 mm；
- GPS 平面精度：1 m；
- GPS 高程精度：1 m；
- 勾选天线分量、航带漂移、线性漂移等改正项。

![iBundle 精度与改正项设置](./12-accuracy-settings.png)

这些值不是越小越好。它们应反映控制点、POS 和量测的真实质量；不合理地把先验精度设得过高，只会让模型“看起来严格”，不会凭空提高数据质量。

### 5.5 阅读平差报告

运行结束后打开“处理 → 平差报告”。本次实验报告中，7 个控制点的统计结果为：

| 指标 | RMS 误差 | 最大误差 |
| --- | ---: | ---: |
| X | 0.1818 m | 0.3128 m |
| Y | 0.0829 m | 0.1124 m |
| XY | 0.1998 m | 0.3269 m |
| Z | 0.5800 m | -1.1810 m |

课程要求可概括为平面误差控制在约 0.5 m 内、高程误差控制在约 0.7 m 内。应同时查看单点残差，不能只看总体 RMS。示例中点 1006 的高程残差达到 -1.1810 m，值得重新检查刺点和点位质量。

此外，这份实验报告的 **检查点数量为 0**。这意味着表中反映的是参与平差的控制点残差，而不是独立检查精度；它可以用于诊断模型，但不能替代独立检查点验证。

精度不合格时，应回到刺点界面修正误差大的控制点，或补充空间分布合理的控制点，再重新平差。平差通过后输出方位元素，供 DEM、DOM 和立体测图使用。

## 6. 生产 DEM 和 DOM

### 6.1 快速整体正射

选择“DOM 生产 → 整体正射”，按教学数据的默认参数运行。

![整体正射任务参数](./13-overall-ortho-parameters.png)

该功能适合快速检查测区是否完整、是否存在明显错位。任务完成后，软件可直接显示快拼结果，并在工程 `Dem` 目录中生成中间 DEM。

![整体正射快速成果](./14-overall-ortho-result.png)

快速结果更适合整体检查。正式成果仍建议经过单张正射、拼接线编辑和正射编辑。

### 6.2 单张正射

选择“DOM 生产 → 单张正射”。教学示例把输出分辨率由 0.2 m 调整为 0.1 m。

![单张正射生产](./15-single-ortho.png)

分辨率应结合原始影像地面分辨率、成图比例尺和任务要求确定，不能简单理解为数值越小越清晰。每张正射通常产生：

- `.tif`：影像像元；
- `.tfw`：对应的地理配准参数。

### 6.3 正射拼接

打开“DOM 生产 → 正射拼接”，在工程的 `Dom` 文件夹中新建拼接工程，再添加全部单片正射 `.tif`。

![载入全部单片正射影像](./16-mosaic-input.png)

选择“处理 → 生成拼接线”。

![自动生成的拼接线](./17-seamlines.png)

自动拼接线只是初始结果。进入“编辑拼接线”后，遵循几个基本原则：

- 拼接线之间不能交叉；
- 尽量绕开房屋屋顶和高大构筑物；
- 穿越道路时尽量与道路平行或近似垂直，避免斜切形成明显错缝；
- 在纹理稳定、色差较小的区域通过；
- 不要为了局部平滑而制造过于曲折的拼接线。

![手工调整道路和建筑附近的拼接线](./18-seamline-edit.png)

编辑完成后先输出拼接线，再执行“处理 → 拼接影像”，以 GeoTIFF 格式保存到 `Dom` 文件夹。

### 6.4 正射与 DEM 编辑

进入“DOM 生产 → 正射编辑”：

1. 打开刚生成的整体 DOM；
2. 载入 `Dem` 文件夹中的 DEM；
3. 载入工程根目录中的测区文件；
4. 在设置中打开等高线显示。

![在正射编辑中叠加 DEM 等高线](./19-ortho-edit-contours.png)

用“选择区域”框选异常范围，结合影像和等高线进行平滑、重纠等操作。重点关注建筑物、陡坎、树冠和拼接边缘。

![框选需要修改的 DEM 区域](./20-dem-edit-area.png)

完成后用新名称另存 DEM，不要直接覆盖最初成果；随后保存编辑后的正射影像。

![DEM 编辑后的整体检查](./21-dem-edited.png)

## 7. DLG 立体测图

先在主程序中新建立体模型，让软件自动加载可用像对。

![建立立体模型并检查像对](./22-stereo-model.png)

选择“DLG 生产 → 立体影像测图”，设置图幅参数、符号比例尺和输出位置，并载入工程中的 `.dpp` 测区文件。

![设置 DLG 图幅和符号比例](./23-dlg-map-parameters.png)

双击一个立体像对开始采集：

- `Ctrl + 鼠标滚轮` 调整图像尺度；
- 鼠标滚轮调节高程，使光标贴合地表或目标顶部；
- 按地物类别选择正确符号，再勾画道路、建筑、水体和植被等要素。

如果已经绘制却在右侧看不到矢量，选择“文件 → 使用地物范围”，并核对比例尺和图幅坐标。

![使用地物范围修正显示范围](./24-fit-feature-extent.png)

![在立体模型中采集 DLG 要素](./25-dlg-drawing.png)

保存 `.dpv` 矢量后，进入“DLG 生产 → 整饰出版”，打开刚才的成果，设置图名、图号、地区、单位和图廓参数。

![DLG 整饰出版界面](./26-map-layout.png)

最后以 JPG 等格式输出成果图。

![整饰后的 DLG 成果图](./27-dlg-result.jpg)

## 8. 成果检查清单

完成任务后，不要只保留一张截图。至少确认下列成果存在且能够重新打开：

- 平差精度报告和输出方位元素；
- DEM 文件及编辑后的备份版本；
- 单片正射 `.tif/.tfw`；
- 拼接线文件和整体 DOM GeoTIFF；
- DLG 矢量 `.dpv`；
- 整饰后的成果图；
- 完整工程目录和处理参数记录。

对于正式项目，还应增加独立检查点、DEM/DOM 质检记录和坐标系统说明。教程中的参数来自教学数据，换一套影像时应根据航高、地面分辨率、地形起伏和成图要求重新确定。

## 常见问题

| 现象 | 最可能的原因 | 处理方法 |
| --- | --- | --- |
| 软件启动提示缺少 DLL | 安装文件被杀毒软件隔离，或运行库不完整 | 将软件加入可信名单后重新安装；在 DBCloud 软件宝库安装运行库合集，必要时修复 DirectX |
| 匹配连接点没有反应 | 账号掉线或许可不可用 | 回到 DBCloud 重新登录并检查许可 |
| 工程可以打开但计算失败 | 路径包含中文、空格或特殊字符 | 把工程迁移到短英文路径后重新建立工程 |
| 运行平差只有黑色命令行窗口 | 未选择 iBundle 平差软件 | 在“处理 → 平差方式”中选择 iBundle |
| 控制点全部偏离测区 | 坐标顺序、投影、单位或带号错误 | 核对 TXT 字段和测区坐标系统 |
| 立体测图右侧没有线 | 地物范围或比例尺不匹配 | 使用“适用地物范围”，再核对 1:2000 等符号比例 |
| 立体窗口无法正常显示 | 显卡或图形接口兼容问题 | 更新显卡驱动；在确认设备条件后再按教学说明切换显卡，避免直接禁用唯一显示设备 |

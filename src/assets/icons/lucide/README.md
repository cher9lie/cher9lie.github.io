# Lucide interface icons

These SVG files come from the official [Lucide repository](https://github.com/lucide-icons/lucide):

- `menu.svg`
- `monitor.svg`
- `moon.svg`
- `search.svg`
- `sun.svg`
- `tag.svg`

They were retrieved on 2026-09-23 and are used for small interface controls. The accompanying `LICENSE` file contains the upstream ISC/MIT license notices.

Apple Design Resources, SF Symbols, and San Francisco font files are intentionally not bundled because their licenses don't permit embedding them as general website assets.
